# Rift SensAI

Real-time AI coaching overlay for League of Legends.

**[Visit the site](https://dkhobby.com/lol-coach/)** · **[Download the latest release](https://github.com/dkyk0929/lol-coach-overlay/releases/latest)**

Rift SensAI reads live match data via Riot's official Live Client Data API and League Client API to give in-game coaching, objective timers, jungler tracking, CS/gold tracking, and a Match Scout panel with opponent rank/history — plus optional AI-generated coaching (Claude or Gemini) and a resizable Dashboard window.

It does not modify game files, inject code into the game process, or provide any form of automation. Not affiliated with or endorsed by Riot Games.

See [release-notes.md](release-notes.md) for the full version history.
