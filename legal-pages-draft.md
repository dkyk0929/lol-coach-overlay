# Privacy Policy

Last updated: [DATE]

Rift SensAI ("the app") is a desktop overlay for League of Legends. This page explains what data the app touches and what we do with it.

## What the app reads

- **Live match data** from Riot's Live Client Data API (runs locally on your machine at 127.0.0.1:2999) — used only to display in-game stats and generate coaching tips while you play.
- **League Client (LCU) data** — rank, champion mastery, and summoner info for players in your current lobby, used for the in-game scout feature.
- **Riot's public API** (if you provide your own Riot API key) — recent match history for players in your lobby, for the same scout feature.

## What the app does NOT do

- We do not collect, store, or transmit your personal information to our servers.
- We do not sell or share any data with third parties.
- We do not access your Riot account credentials, payment information, or anything outside of what Riot's own APIs expose about the current match.

## API keys

If you provide an AI provider API key (Anthropic or Google Gemini) or a Riot API key, it is stored **locally on your machine** and used only to make requests directly from your computer to that provider. We never see or store your keys on any server we control.

## Third-party services

The app makes requests to: Riot Games' Live Client Data API and LCU API (local only), Riot's public developer API (if you supply a key), Anthropic's API and/or Google's Gemini API (if you supply a key), and Riot's Data Dragon CDN for champion/item data. Each of these is governed by that provider's own privacy policy.
