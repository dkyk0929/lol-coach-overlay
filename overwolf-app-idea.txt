RiftCoach AI is a real-time coaching overlay for League of Legends. It reads live match data and gives players spoken, in-the-moment advice — objective timers (Dragon, Baron, Void Grubs, Rift Herald), jungler tracking, CS/gold deltas, recall detection, and situational call-outs (all-in windows, missing laners) — without alt-tabbing out of the game.

What makes it "AI": before each match, it researches your specific champion matchup and itemization using a web-search-grounded AI query, then feeds that research into fast, low-latency coaching tips delivered throughout the game. Post-game, it gives a full breakdown of what went well and what to fix.

Architecture: the app talks to a backend proxy we run (not direct client-side API keys), which routes requests to different AI models by task — a stronger model for the few high-reasoning calls per game (matchup research, post-game analysis), a fast/cheap model for frequent in-game pulses, triggered by actual game events (kills, deaths, item completions, objective spawns) rather than blind timers, to keep latency and cost low. Players can optionally supply their own API key for unlimited use.

We're applying for Overwolf specifically for GEP access — our current data source (Riot's Live Client API) has no vision/fog-of-war data, which limits jungler and missing-laner tracking to heuristics (item-purchase-based recall detection, manual pings). GEP's documented jungle-camp and cooldown data would let us replace guesswork with real tracking, and the overlay window type would let the HUD render over true exclusive fullscreen instead of requiring Borderless Windowed.
