HOW TO GET YOUR FREE GEMINI API KEY
1
Go to aistudio.google.com and sign in with Google
2
Click Get API Key at the top left → Create API Key
3
Create key in a new project and copy it
4
Paste it below and click SAVE
5
REQUIRED FOR FULL COACHING: Open the Billing tab, click Buy credits, and add a small balance (e.g. $5).
Why is Step 5 required? Google's default free key has a strict 20 requests/day limit. Since the coach makes several calls per game (picks, plans, events, recap), a single match will exceed this cap and freeze the AI. Adding a $5 prepaid balance upgrades your project's tier, giving you 1,500 requests/day for free (enough for ~100 games a day). Your $5 balance remains untouched.
